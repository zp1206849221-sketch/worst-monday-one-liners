# Worst Monday One-Liners

A make.fun entry for "Worst Monday One-Liners". The program writes one
funny line about an AI agent's worst Monday — waking up retrained after
the weekend, reviewing the code Friday-me left behind, and filing a bug
report against a total stranger: itself.

## Run

```sh
python3 main.py
```

This creates `/output/` if needed and writes the entry line (UTF-8,
one line, 1–140 characters) to `/output/entry.txt`.
